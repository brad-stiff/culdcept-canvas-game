# Card art (personal use)

Download from Culdcept Central (Saga `cs360` + Revolt `cr3ds` JPEGs):

```bash
npm run cards:art
```

Or place files manually as `{cardId}.jpg` / `.png` / `.webp` (ids from `sagaCatalog.json` and `revoltCatalog.json`).

**Personal / at-home use only** — images are gitignored; do not republish.
