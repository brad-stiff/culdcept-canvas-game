# Card art (personal use)

Download from Culdcept Central (Saga `cs360`, Revolt `cr3ds`, PS2 `cps2` JPEGs):

```bash
npm run cards:art
```

Or place files manually as `{cardId}.jpg` / `.png` / `.webp` (ids from `sagaCatalog.json`, unique-name `revoltCatalog.json`, and `ps2Catalog.json`).

**Personal / at-home use only** — images are gitignored; do not republish.
