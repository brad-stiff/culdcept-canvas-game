# Card list sources

`culdcept-saga-complete-card-list.md` is a markdown export of the
[Culdcept Central Saga complete card list](https://culdceptcentral.com/culdcept-saga/culdcept-saga-card-lists/culdcept-saga-complete-card-list)
used to generate `src/shared/cards/sagaCatalog.json`.

Regenerate:

```bash
npm run cards:parse -w app
```
